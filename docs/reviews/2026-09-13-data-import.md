## R1: 再取得失敗で保存済みZIPが失われる

- [初回の指摘コメント](https://github.com/codiy3/google-maps-extended/pull/2#issuecomment-5652716885)
- 対象: アプリREADMEのデータ取得手順。
- 発生条件: 同じ出力先へのcurlを再実行し、通信が途中で失敗する。
- 影響: 読み込み時のハッシュ照合で不完全データの使用は防げるが、保存済みZIPを失う可能性がある。
- 対応: `cdd1a1e`。検証済みファイルを再利用し、新規取得は一時ファイルへ保存する。SHA-256が一致した時点で確定する。既存ファイルの不一致は上書きせずエラーとする。
- 再確認: 保存済みファイルの再利用、不一致時の保護、取得成功、通信中断と取得内容の不一致をテストした。公式ZIPを新規取得するCLIも実行し、台帳の再生成まで成功した。
