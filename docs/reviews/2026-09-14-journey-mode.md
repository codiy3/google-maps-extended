基準: `0a957f3`。初回対象: `9f21833`。担当者自身によるレビューであり、第三者承認ではない。

## 指摘

- R1 / P2: スマートフォンで入力欄の下までスクロールして再検索すると結果の先頭が画面外に残る。結果へスクロールし、共通パネルの経路・駅詳細・種別へ移動する導線を用意する。
- R2 / P2: 地図から外した路線の種別条件が残り、見えない制約として次の検索に送られる。明示的な路線解除時には条件も解除し、モード切替では保持する。
- R3 / P2: 全入力が同一駅でも未取得時刻表のため0分を返せない。移動なしと、別駅を回る経路を区別する。線形がない時間経路も表示範囲を明記する。
- R4 / P2: HMRでGoogle SDK設定が再実行され、警告に設定値が含まれる。初期化状態をHMR間で保持する。
- R5 / P2: 経由駅が降車可・乗車不可の場合、同じ便で継続乗車できる経路も除外していた。継続乗車とその駅からの新規乗車を区別する。

初回確認: Python 40件、フロント36件、ruff・mypy・Biome・TypeScriptが成功。Demo Keyで和光市→渋谷、飯田橋経由、従来の駅詳細表示を操作した。実時刻表は未取得であり、時間のアルゴリズムは架空のテストデータで検証した。
