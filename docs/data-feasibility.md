# 全国データの取得と不足の調査

調査日: 2026-09-13。駅・線路の元データは取得済み。全国の運行系統、種別・停車パターン・時刻表の確保は未完了。

## 実際に取得したデータ

国土交通省の[N02・2025年版](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html)の公式ZIPを取得し、UTF-8のGeoJSONを全件読み込んだ。基準日は2025-12-31、元の座標系はJGD2011（EPSG:6668）。当該版はCC BY 4.0のオープンデータとして案内されている。派生ファイルには出典と加工した旨を保持する。[利用条件](https://nlftp.mlit.go.jp/ksj/other/agreement_01.html)

以下は取得したファイルをプログラムで集計した件数であり、現在営業している路線や駅の実数ではない。

| 元データの集計項目 | 件数 |
| --- | ---: |
| 線路の地物 | 21,933 |
| 駅の地物 | 10,234 |
| 駅コードの異なり数 | 10,154 |
| 駅グループコードの異なり数 | 9,046 |
| 会社欄と路線名欄の組み合わせ | 597 |
| 駅コードが重複する追加の地物 | 80 |

集計元: [生成した集計結果](../google-maps-railway-viewer/data/catalog/n02-summary.json)、[全組み合わせの調査台帳](../google-maps-railway-viewer/data/catalog/n02-route-inventory.csv)。入力ZIPのSHA-256は集計結果と読込処理に記録している。

## 実データで分かった補完事項

1. JR東日本の「山手線」に属する駅コードは17件。希望されている環状運転の30駅と一致しないため、別の線路名で収録された区間との対応付けが必要。17件を「山手線の全駅」としてアプリへ渡さない。
2. JR東日本の「中央線」は駅コード72件。中央線快速や中央・総武各駅停車という運行系統の駅集合と同一とは扱えない。Osaka Metroの中央線は「4号線(中央線)」の名前で収録されている。別名と対象区間を根拠付きで整備する。
3. 会社欄が「三国芦原線」、路線名欄が「えちぜん鉄道」という組み合わせの線路があり、その組み合わせの駅は見つからない。逆の組み合わせには駅があるため、属性の入れ替わりの可能性として検出した。元データを自動で書き換えず、公式資料との照合対象にする。
4. 同じ駅コードに複数の線形がある。駅数には駅コード単位の重複除去を行うが、地物数も保存する。別会社や別路線の駅を、名前やグループコードだけで1駅に統合しない。
5. N02の駅・線路には都道府県属性、列車種別、停車パターン、時刻表がない。都道府県は行政区域データと照合し、残りは運行情報の提供元から補完する。緯度順の駅コードを列車の停車順に利用しない。

## 無料の種別・時刻表の候補

| 提供元 | 確認した範囲 | 現時点の扱い |
| --- | --- | --- |
| [ODPT・JR東日本の列車時刻表](https://ckan.odpt.org/en/dataset/jreast__r_train_timetable) | 関東の一部在来線。新幹線や中央線・青梅線の特急等を含まない。チャレンジ2026限定の案内 | 全国対応・恒久利用の根拠にはできない。登録と個別の利用条件、対象便・期間の確認が必要 |
| [ODPTの公開データ一覧](https://challenge2026.odpt.org/ja/opendata.html) | 鉄道を含む複数事業者のデータが案内されている | 提供会社の存在だけで、必要な全路線・全種別・全便が取得できるとは判定しない |
| [GTFSデータリポジトリ](https://gtfs-data.jp/) | 鉄道を含む事業者ごとの公開GTFSを探せる | 個別フィードの路線、適用日、種別情報、ライセンスの確認が必要。API仕様ページは今回タイムアウトし、網羅的な取得は未実施 |
| [JR東海の公開時刻表案内](https://global.jr-central.co.jp/en/info/timetable/) | 基本時刻表で全列車を掲載するものではないと案内 | 閲覧可能なことを、自動取得・加工・再配布が許可される根拠にしない。[サイト利用案内](https://jr-central.co.jp/policy/)を確認し、アプリ向けの採用は保留 |

無料の全国時刻表が存在しないと断定する調査ではない。今回確認した取得元では、全要件を継続0円で満たす根拠をまだ確保できていない。各社の時刻表は未取得で、台帳の`not_in_source`は「N02には含まれない」を意味する。他の公開元にも存在しないという意味ではない。

## 実装に進める部分とリリース前の条件

駅・線路の読込、同名路線の識別、検索画面、Google マップへの描画、macOSでの起動処理は順に開発できる。開発中の画面ではデータの収録範囲と未対応を明示する。以下の補完が終わるまでは、全国の全機能を備えたリリースとはしない。

- 都道府県との照合と、利用者向け運行系統・別名・駅所属の対応付け。
- 線形の欠落・誤接続、属性の不整合、データ基準日後の開業・廃止の確認。
- 路線ごとの種別、停車パターン、運転日、時刻精度、有効期間、継続0円での利用条件の確認。
- 全国の対象一覧に対する不足の解消。無料の取得元で解消できない場合は、不足を具体的に示し、ユーザーと範囲または予算を判断する。

元データの会社・路線名は照合用の値として保存する。`source_entry_id`はこの版の元データを参照するIDであり、名称変更をまたぐアプリの恒久IDとは別にする。手動の照合結果は生成台帳へ直接書き込まず、別の対応データとして管理する。
