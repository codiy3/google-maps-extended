# 乗換案内モード

更新日: 2026-09-14。利用者の追加要件と実装・検証の境界を記録する。

## 画面と共通機能

- 「路線検索」「乗換案内」の2モードを設ける。モード変更で選択路線・駅詳細・種別フィルターを失わない。
- 乗換案内に出発駅・到着駅・経由駅の入力を設け、同名駅は路線・会社・路線の地域を表示して選択する。
- 経由駅は追加・削除・上下移動でき、指定順に通る。画面上の個数を固定しない。滞在時間は今回含めない。
- 経路と沿線の表示を区別しながら、路線の追加、色分け、赤ピン、駅名、駅の吹き出し、直通・乗換先、到着時刻欄、種別フィルターを共用する。
- 最短距離と最短時間を別の結果として表示し、条件変更後に旧条件の結果を確定結果として残さない。

## 計算する距離

国土数値情報の線路形状上の概算走行距離を最小化する。徒歩・改札内移動の距離は原典にないため含めない。駅の表示点はホーム線形の代表点であり、営業キロ・運賃距離ではない。

路線ごとに線形を接続し、同一駅グループだけで別路線へ移動する。立体交差や別会社の近接線を位置だけで乗り換え可能にしない。断線した経路を任意の直線で補わない。乗車可否・列車の運転日を確認できない結果は「線路データ上の候補」と表示し、運行を保証した乗換案内と区別する。

## 計算する時間

時刻表がある範囲で、指定出発日時からの予定到着が最も早い経路を探す。路線検索の「待ち時間を含めない最短乗車時間」と区別する。乗換案内では列車待ち時間を含み、乗換余裕時間は画面の設定値として扱う。実測の駅構内移動時間とみなさない。

運転日、24時以降の時刻、乗降可否、選択した種別、経由駅の順序を照合する。未取得の時刻や推定時刻から確定の到着時刻を作らない。収録時刻表がない現在は「時刻表未取得のため未計算」と表示する。

ODPTは引き続き必須にしない。Google通常キーへの切替、課金やAPI制限の変更、Google応答の恒久保存はこの機能の実装条件にしない。既存の正規化済み時刻表の取り込み口を利用する。
