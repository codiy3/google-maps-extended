# 路線検索の設計

更新日: 2026-09-13

状態: 全国の候補表示と会社・都道府県による識別はユーザー指定の要件。入力候補・会社と地域の表示・キーボード操作を実装した開発版がある。全国の運行系統・別名・安定IDの照合は未完了であり、以下の全受け入れ条件を満たす正式リリースではない。

## 利用の流れ

1. 検索欄に路線名を入力する。検索ボタンを押す前から候補を表示する。
2. 検索欄の直下に、正式名称・案内名称・確認済みの別名が一致する路線を並べる。
3. 各候補に路線名、鉄道会社、都道府県、識別に必要な対象区間を表示する。
4. 利用者が候補をクリック・タップして確定すると、対象路線の全駅と線形を読み込む。
5. 選択済みの路線名を画面に残し、どの候補を表示しているか確認できるようにする。

## 同じ名前を持つ路線の扱い

「中央線」は、完全一致する名称だけを探すのでは足りない。利用者が指定した検索例として、JR中央本線、大阪メトロ中央線、中央線（快速）、中央・総武線各駅停車を検索できるようにする。正式名称と通称の対応を確認して検索用の別名を登録する。

JR東日本の路線案内では中央線快速電車と中央・総武各駅停車を別の運行系統として案内している。Osaka Metroにも中央線がある。実装時には各社の路線案内と取得データを照合する。[JR東日本の関東エリア案内](https://traininfo.jreast.co.jp/train_info/kanto.aspx)、[Osaka Metroの路線情報](https://subway.osakametro.co.jp/station_guide/index.php)

候補の表示形式は次のとおりとする。

| 表示箇所 | 内容 |
| --- | --- |
| 1段目 | 路線・運行系統名。快速・各駅停車など名称の一部を省略しない |
| 2段目 | 鉄道会社名と沿線の都道府県 |
| 補助表示 | 対象区間の始終点、会社別区間、直通区間を含むかどうか |

複数の都道府県にまたがる路線は、該当する都道府県を一覧で保持する。長い場合は折り返すか「ほかN都県」を展開できるようにし、クリック前でも全地域を確認できるようにする。最寄りの県だけを表示して他地域の候補を隠さない。

中央本線のように会社別の区間がある場合は、対象区間と会社を明示して候補を区別する。全区間を含む候補を用意する場合も、会社別区間と同じIDで扱わない。候補を作る単位と所属駅は、全国データ整備時に一覧化して照合する。

## 検索データ

| 項目 | 役割 |
| --- | --- |
| `line_id` | 名称変更や同名路線に影響されない、アプリ内の識別子 |
| `display_name` / `official_names` | 画面上の名称と出典上の正式名称 |
| `entry_kind` | 線路の路線か、利用者向けの運行系統かの区別 |
| `operator_ids` | 対象区間を運行する会社。会社名だけを主キーにしない |
| `prefecture_codes` | 対象の駅・線形に照合した都道府県の一覧 |
| `section` | 対象区間の始終点と直通区間の取り扱い |
| `aliases` / `readings` | 確認済みの通称・旧称・読み。旧称には現在名を案内する |
| `source_refs` / `validity` | 名称・地域・所属の出典と有効期間 |

路線と運行系統は関連付けて保持する。同じ線路を使っても、検索候補として区別する必要がある場合は別の`line_id`を割り当てる。「快速」という語を検索用に除去して、中央線（快速）と他の運行系統を統合する処理は行わない。

## 検索と操作の詳細

- 入力文字の全角・半角、英字の大小、前後の空白などを検索時に正規化する。元の表記は保存する。
- 正式名称・表示名の完全一致、確認済み別名の完全一致、前方一致、部分一致の順で候補を並べる。同順位では安定した順序を使う。
- 「中央線」から「中央本線」を探す関係は、確認済み別名で扱う。文字が似ているだけで所属を推定しない。
- 1文字以上の入力で検索する。候補一覧に高さの上限を設け、残りはスクロール等ですべて選べるようにする。
- 読みのデータがある場合はひらがな・カタカナの入力にも対応する。読みが不明な固有名詞を推測して登録しない。
- 日本語の変換中はEnterによる候補選択を抑止する。変換確定後に候補を更新する。
- 上下キーで移動、Enterで選択、Escapeで候補を閉じる。スクリーンリーダーに候補数と選択状態を伝える。
- 入力中の検索文字と選択済みの路線を別に保持する。文字を消しても、選択解除を明示操作するまでは表示中の地図を残す。
- 候補を素早く切り替えた場合も最後に選択した路線だけを表示する。
- 取得に成功して一致しない場合は「該当する路線なし」、取得に失敗した場合は再試行できるエラーを表示する。

全国の路線名・会社・地域・別名を収めた索引を事前生成し、入力中はアプリ側で照合する案を基本とする。外部サービスを使う場合は利用条件に応じたサーバー側検索へ切り替えられる構成にする。Googleの施設検索結果を路線一覧の代用にしない。

## 受け入れ確認

- 「中央線」入力だけで、上記の路線・運行系統を含む全国の該当候補が表示される。
- 同名路線、複数県、同じ会社の異なる区間を候補表示だけで識別できる。
- 候補数が表示領域を超えても、後方の候補を選択できる。
- 変換確定、キーボード操作、タッチ操作で誤選択が発生しない。
- 別路線の入力中も選択済み路線が分かり、確定後は地図と駅一覧が同じ路線に切り替わる。
- 検索用索引の路線・運行系統一覧を、全国の対象一覧と照合する。例示した路線だけを手作業で追加して全国対応完了と扱わない。
